'@nestvexa/vite': minor

Add `@nestvexa/vite`: per-app Vite manifest lookup with validated output paths,
nonce-bound script/CSS/modulepreload tags, immutable static serving from a
startup index (no request path reaches the filesystem), in-process SSR bundle
rendering with classified failures, the official Inertia SSR server launcher
(loopback by default), Vite middleware-mode dev server with SSR reload, a
per-request CSP nonce middleware, an Inertia root view and the browser-safe
page registry. Vite is an optional peer and is never imported in production.
