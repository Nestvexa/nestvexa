Add React, Vue and Svelte adapters for the official `@inertiajs/react`,
`@inertiajs/vue3` and `@inertiajs/svelte` 3.10.0 clients: explicit page
registries, client entries that hydrate server markup (React `hydrateRoot`, Vue
`createSSRApp`, Svelte 5 `hydrate`) or mount, error boundaries, and SSR render
functions on the official server path usable in-process or through the official
SSR HTTP server. Frameworks and clients are peer dependencies.
