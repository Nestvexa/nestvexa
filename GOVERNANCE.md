# Governance

The repository owner approves releases, appoints maintainers and controls security contacts. Public API changes require an ADR, compatibility notes, tests and a Changeset. Future maintainers should document decisions in reviewed pull requests. No individual or organization is asserted as owner without supplied information.

Publication, remote pushes and official tags require explicit owner authorization. Feature acceptance follows the master implementation specification; unfinished mandatory work cannot be relabeled complete through governance.
