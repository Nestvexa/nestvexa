## Chapter applicability assessment (2026-11-14)

Internal assessment by the project, not an independent review. It covers all
17 ASVS 5.0.0 chapters at chapter (and, where named, section) level, so that
no chapter is left unassessed. It does not replace a requirement-by-requirement
review: the tables above hold the identifiers checked so far, and a chapter
marked Implemented can still contain requirements nobody has mapped yet.

Statuses: **Implemented** (Nestvexa controls with tests cover the framework's
part of the chapter); **Partial** (some framework controls are tested, listed
gaps remain); **Host responsibility** (Nestvexa provides no control: the
application or operator owns it; an example may demonstrate it); **Not
applicable** (no Nestvexa feature touches the chapter); **Gap** (applicable,
and no control exists yet).
