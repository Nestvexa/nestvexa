# Feature matrix

Maps the [master specification](../NESTVEXA_MASTER_IMPLEMENTATION_PROMPT.md) to packages
and their real status on **2026-11-07** (`0.1.0-alpha.0`). Each status below was checked
against the code, the tests and the package README's "Status and limits" section. The
machine-readable [feature ledger](implementation/feature-ledger.md) (`feature-ledger.json`)
is updated from agent reports by the coordinator, so its row states can lag the code. When
this page and a package README disagree, the README and its tests are the evidence.

Status words used below:

- **Shipped (alpha)** — implemented, covered by integration and (where relevant)
  three-browser tests, documented, packed. Still alpha: no stability promise.
- **Partial** — the core behavior works and is tested, but named clauses are missing.
- **Missing** — not implemented. Do not rely on it.
- **By design** — deliberately not provided; the linked ADR explains why.

Nothing here is release-ready: an independent security review and load, fuzz and
mutation testing have not been executed ([status](implementation/STATUS.md)). The
two-replica Redis browser run has been executed against Redis 7
([services evidence](implementation/services-evidence-2026-11-05.json)).

## Product modes

| Mode (spec 1.3)            | Works today                                                                                                                                                         | Main gaps                                                                                                                      |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| MVC                        | HBS default, EJS/Pug/Nunjucks adapters, nested layouts, namespaces, themes, route/meta/permission/asset helpers, error pages, escaping, cache — **Shipped (alpha)** | The umbrella `views` config takes only engine, root, cache and layout; no streaming in any engine (VIEW rows)                  |
| Live                       | Decorated components, actions, computed, locked/URL/session state, nesting, events, effects, directives, shared Redis store — **Partial**                           | Redis Cluster unsupported; cross-replica replay on real Redis (LIVE-007); remaining client acceptance rows (PROT-012)          |
| Inertia (React/Vue/Svelte) | Server adapter for the v3 protocol, Precognition, official clients, Vite manifest/dev/SSR, CLI roots — **Partial**                                                  | `shareOnce` sugar and error-page helpers missing; scroll and progress indicator not asserted (INERT rows)                      |
| Hybrid                     | Allowlisted islands in HBS/Live pages with SSR, signed props, event bridge, bundle budgets, esbuild or Vite builds — **Shipped (alpha)**                            | Live and Inertia do not share one client-side navigation; Vue attribute-only mismatches unreported in production (ISLAND rows) |
| API coexistence            | Host REST routes untouched; opt-in universal actions with `202` jobs and tracing — **Partial**                                                                      | GraphQL/microservices coexistence untested; no incremental action result streaming; process-local action stores (ACT rows)     |
