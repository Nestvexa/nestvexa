# Agent report: documentation, architecture and governance

Ledger groups: DOC, ARCH, UPSTREAM, VISION, MISSION. Branch
`worktree-agent-a98c4bbb190533d87`, based on `main` at `20f6894`. No package source
changed. New tooling: the documentation site builder in `apps/docs`, with
`marked@18.1.3` as an exact root dev dependency. New test file:
`tests/docs-site.test.ts`, in `test:integration`.

The documentation site is built and verified by `pnpm docs:build`. It needs
`pnpm build` first because it reads the built packages. The design is recorded in
[ADR 0027](../../adr/0027-documentation-site.md).

**What the build fails on:**

- page structure: one H1, no skipped heading levels;
- broken relative links, and anchors that do not match GitHub slugs;
- absolute links;
- snippet provenance: `<!-- snippet: path -->` fences must still match their source
  file;
- CLI commands in the docs that `nestvexa --help` does not list;
- drift between `package-dependency-graph.md` and the `package.json` files;
- packages missing from the feature matrix or the architecture overview;
- unbuilt `.d.ts` entry points.

**What it writes** to `artifacts/docs`:

- 177 pages;
- 29 API reference pages covering 946 exports, generated with the TypeScript
  compiler API;
- `api/api.json`.

Last run: 44 provenance snippets verified.

## Notes for the coordinator when merging

- **Docs drift fails `pnpm docs:build` after merges.** This is intended. Expect it
  when:
  - **Packages are added:** a branch that adds a package or a workspace dependency
    must add it to `docs/architecture/package-dependency-graph.md` (node and edge),
    `docs/feature-matrix.md` and `docs/architecture/overview.md`.
  - **CLI commands change:** if the CLI branch adds commands, the CLI check validates
    them against `--help`. Commands it documents but does not implement will fail.
  - **Status changes:** after the CLI branch merges, the feature matrix and ROADMAP
    rows for `make:form/action/island/test` and `add react|vue|svelte` must be
    refreshed.
  - **Pages are added:** new guide pages need nothing; `nav.json` include globs pick
    them up.
- **`package.json` changes:**
  - added `marked@18.1.3` to `devDependencies`, which also changes the lockfile;
  - `lint` now includes `apps`;
  - `tests/docs-site.test.ts` added to `test:integration`.
- **No Playwright entries.** No servers or ports were used.
- **Owner questions:**
  - the npm 404 versus the STATUS.md publication claim;
  - ARCH-010 (Live → core edge);
  - whether to adopt Node 26 LTS.
