`cli-generators.md`, `dev-error-page.md`.

`tests/cli-generators.test.ts` builds a strict ESM Nest app
(`strict`, `exactOptionalPropertyTypes`, `noUncheckedIndexedAccess`) whose
`node_modules` junction the workspace packages and the frontend toolchain of
`examples/inertia-mixed`, runs every command, type-checks **all** generated output
with `tsc` (server, React root, islands), `vue-tsc` (Vue root) and `svelte-check`
(Svelte root), runs the generated unit tests (vitest on the compiled output),
then boots the generated app on port 3241 and exercises it over HTTP. No packed
tarball install is done (optional per assignment).
